## What moved and why

The calendar and stock/index timing are identical to the first rehearsal. The only input change is delaying each ISIN snapshot until the next session. This removes newly identified symbols on the snapshot date from eligibility and breadth/basket membership. It also changes V3 basket returns for later decisions whose windows include those dates, and slightly shifts the pooled volatility-quintile boundaries. Population, cell counts and coverage therefore move even though stock-bar timing is unchanged. Spells and usable-draw counts are shown above; no outcome-based selection was made.

The assumption labels and calendar defaults now match the recorded protocol. No source was downloaded; no durable store or Windows task was modified. Part 2 remains deferred.
